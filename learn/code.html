Code is just text

Code ist einfach Text

Every file of the game is plain text, the same letters you type in a message. It's written in a language the computer understands, called JavaScript.

Jede Datei des Spiels ist einfacher Text, dieselben Buchstaben, die du in einer Nachricht tippst. Er ist in einer Sprache geschrieben, die der Computer versteht: JavaScript.

The computer reads it from top to bottom, and does exactly what it says. Here is the start of a real file of the game. The colours help you read it:

Der Computer liest ihn von oben nach unten und macht genau, was dasteht. Hier ist der Anfang einer echten Datei des Spiels. Die Farben helfen dir beim Lesen:

  • grey: comments. Everything after // is a note for people. The computer skips it.
  • grau: Kommentare. Alles nach // ist eine Notiz für Menschen. Der Computer überspringt sie.
  • orange: words of the language itself, like const, function, if, return. There are only a few dozen.
  • orange: Wörter der Sprache selbst, wie const, function, if, return. Davon gibt es nur ein paar Dutzend.
  • blue: numbers. green: text in quotes.
  • blau: Zahlen. grün: Text in Anführungszeichen.
  • white: names that the game's makers made up, like CAST_TIME.
  • weiß: Namen, die sich die Macher des Spiels ausgedacht haben, wie CAST_TIME.

      
That is the town portal scroll: you stand still for 5 seconds to open it, then stand in it for 1 second to go through.

      
Das ist die Stadtportal-Schriftrolle: Du stehst 5 Sekunden still, um es zu öffnen, und dann 1 Sekunde darin, um hindurchzugehen.

      
English Code and its comments are written in English, almost everywhere in the world, even by people who speak other languages.

      
Englisch Code und Kommentare sind auf Englisch, fast überall auf der Welt. Beim Code-Lesen lernst du also nebenbei auch ein paar englische Wörter.

    

  






  
Names for values

  
Namen für Werte

  

    

      
Most lines of code give a name to a value, so the rest of the game can use the name. Such a name is called a variable.

      
Die meisten Codezeilen geben einem Wert einen Namen, damit der Rest des Spiels den Namen benutzen kann. So ein Name heißt Variable.

      

      
    
        
  • const means: this name is fixed. N is 16, forever. A cube is 16 cells wide.
    • 
        
  • const heißt: Dieser Name steht fest. N ist 16, für immer. Ein Würfel ist 16 Zellen breit.
    • 
        
  • = does not mean "is equal", like in maths. It means "put this value into this name".
    • 
        
  • = heißt nicht "ist gleich" wie in Mathe. Es heißt: "Leg diesen Wert in diesen Namen."
    • 
        
  • export means: other files may borrow it.
    • 
        
  • export heißt: Andere Dateien dürfen ihn sich leihen.
    • 
        
  • Numbers use a dot: 2.8, not 2,8.
    • 
        
  • Zahlen haben einen Punkt statt eines Kommas: 2.8, nicht 2,8.
    • 
      

    

    

      
Some values change while you play. Those are made with let. The music remembers its mood like this:

      
Manche Werte ändern sich beim Spielen. Die macht man mit let. Die Musik merkt sich ihre Stimmung so:

      

      
Later, when a fight starts, another line puts new text into mood, like 'fight'. Text is always in quotes, so the computer knows it isn't a name.

      
Später, wenn ein Kampf anfängt, legt eine andere Zeile neuen Text in mood, zum Beispiel 'fight'. Text steht immer in Anführungszeichen, damit der Computer weiß, dass es kein Name ist.

      
Why names? If the run speed were written as 2.8 in twenty places, changing it would mean finding all twenty. With a name, you change one line.

      
Warum Namen? Wenn das Renntempo an zwanzig Stellen als 2.8 stünde, müsste man zum Ändern alle zwanzig finden. Mit einem Namen änderst du eine Zeile.

Try it: functions are little machines

  
Probier es: Funktionen sind kleine Maschinen

  

    

      
A function is a machine with a name. You put something in, it does its work, and something comes out.

      
Eine Funktion ist eine Maschine mit einem Namen. Du steckst etwas hinein, sie macht ihre Arbeit, und etwas kommt heraus.

      

      
Read it like this: "maxHealth is a machine. Give it a level, and => out comes 100, plus 10 for every level above 1." (The numbers come from the object PLAYER.)

      
Lies es so: "maxHealth ist eine Maschine. Gib ihr ein level, und => heraus kommt 100, plus 10 für jedes Level über 1." (Die Zahlen kommen aus dem Objekt PLAYER.)

Größere Maschinen schreibt man mit function name(eingabe) { ... }, und sie sagen mit return, was herauskommt. Dieselbe Idee.

Doing it again: loops

  
Noch mal und noch mal: Schleifen

  

    

      
Every frame, the game has to look at every monster: is it dead? Then you get its experience and its loot. Nobody would write that out for each monster. A loop does it:

      
In jedem Bild muss das Spiel sich jedes Monster anschauen: Ist es tot? Dann bekommst du seine Erfahrung und seine Beute. Niemand würde das für jedes Monster einzeln hinschreiben. Eine Schleife macht das:

      
for (const e of list) {
  const reward = awardKill(player, state.run, e);
  if (reward) {
    xp += reward.xp; levels += reward.levels; killed++;
    if (droppedHere(e)) dropLoot(e, reward.coins);
    if (e.guardianGate) {
      unlocked = enemyName(e.profile);
      log('guardian', { ... }, { share: true });
    }
    relay.defeated?.(e);
  }
}

      
droppedHere(e): playing together, only the game of whoever struck the last blow drops the loot. unlocked keeps the guardian's name, for the message "Temp Boss Spider defeated · Gate unlocked!" (and if it was a boss, the code after the loop plays his victory jingle). log(...) writes a beaten guardian into the game's diary, the chat box. relay.defeated?.(e) tells the friends you play together with; the ?. means: only if there are any.

      
droppedHere(e): Beim Zusammenspielen lässt nur das Spiel dessen, der zuletzt zugeschlagen hat, die Beute fallen. unlocked merkt sich den Namen des Wächters, für die Meldung „Temp-Boss-Spinne besiegt · Tor offen!“ (und war es ein Boss, spielt der Code nach der Schleife seine Sieges-Melodie). log(...) schreibt einen besiegten Wächter ins Tagebuch des Spiels, die Chat-Box. relay.defeated?.(e) sagt es den Freunden, mit denen du zusammen spielst; das ?. heißt: nur, wenn es welche gibt.

      
Read it as: "for each monster e of the list, do what's in the curly brackets". The first time round, e is the first monster, then the second, and so on, until the list is done.

      
Lies es so: "Für (for) jedes Monster e aus (of) der liste, mach, was in den geschweiften Klammern steht." Beim ersten Durchlauf ist e das erste Monster, dann das zweite, und so weiter, bis die Liste fertig ist.

      
xp += reward.xp is short for xp = xp + reward.xp: add to what's there. killed++ adds one.

      
xp += reward.xp ist kurz für xp = xp + reward.xp: zu dem dazuzählen, was schon da ist. killed++ zählt eins dazu.

    

    

      
Sometimes you just want to count. A guardian drops several weapons:

      
Manchmal willst du einfach zählen. Ein Wächter lässt mehrere Waffen fallen:

      
for (let i = 0; i < g.count; i++) out.push(rollWeapon(R, level, { ...g, favor, ...(own && i === 0 && { kind: own }) }));

      
own && i === 0: a boss with a weapon of his own (Renew and his flails) always drops one of those first, the first time round.

      
own && i === 0: Ein Boss mit einer eigenen Waffe (Renew und seine Flegel) lässt beim ersten Durchlauf immer eine davon fallen.

      
This one has three parts, separated by ;:

      
Diese hat drei Teile, getrennt durch ;:

      
    
        
  1. let i = 0: start counting at 0,
    2. 
        
  2. let i = 0: bei 0 anfangen zu zählen,
    3. 
        
  3. i < g.count: keep going while i is less than the number of weapons,
    4. 
        
  4. i < g.count: weitermachen, solange i kleiner ist als die Zahl der Waffen,
    5. 
        
  5. i++: after each round, add one.
    6. 
        
  6. i++: nach jeder Runde eins dazuzählen.
    7. 
      

      
Each round, out.push(...) rolls a new weapon and adds it to the end of the list out.

      
In jeder Runde würfelt out.push(...) eine neue Waffe und hängt sie hinten an die Liste out an.

      
{ ...g, favor } is a new object with everything from g in it, and also favor: the kind of weapon you fight with, so the machine rolls more of those.

      
{ ...g, favor } ist ein neues Objekt mit allem aus g darin und dazu favor: die Art Waffe, mit der du kämpfst, damit die Maschine mehr davon würfelt.

    

  






  
Borrowing from other files

  
Von anderen Dateien leihen

  

    

      
A file can only use what it made itself, or what it borrowed. The first lines of a file usually say what it borrows:

      
Eine Datei kann nur benutzen, was sie selbst gemacht hat, oder was sie sich geliehen hat. Die ersten Zeilen einer Datei sagen meistens, was sie sich leiht:

      
import { createInventory, addInstance, addItem, equipItem, assignBar, whole } from './inventory.js';
import { OLD_SWORD, TOWN_PORTAL, HEALTH_POTION } from './items.js';
import { fixedWeapon } from './gear/generate.js';

      
"From the file inventory.js next to me, borrow createInventory, addItem..." The other file must have put export in front of them, or they can't be borrowed.

      
"Aus der Datei inventory.js neben mir leih dir createInventory, addItem..." Die andere Datei muss export davorgeschrieben haben, sonst kann man sie nicht ausleihen.

    

    

      
That's how 200 small files become one game. Every arrow in the picture of the parts is made of lines like these.

      
So werden aus 200 kleinen Dateien ein Spiel. Jeder Pfeil im Bild der Teile besteht aus solchen Zeilen.

      
It also helps you find your way: if you wonder where OLD_SWORD comes from, the import line tells you: items.js.

      
Es hilft dir auch beim Zurechtfinden: Wenn du dich fragst, wo OLD_SWORD herkommt, sagt dir die Import-Zeile: items.js.

Talking to the game

  
Mit dem Spiel reden

  

    

      
So far, you read the game's code. The game can read too: what you type into its chat box. Press Enter in the game and type. A line is chat. A line that starts with / is a command, an order for the game:

      
Bisher hast du den Code des Spiels gelesen. Das Spiel kann auch lesen: was du in seine Chat-Box tippst. Drück im Spiel Enter und tipp. Eine Zeile ist Chat. Eine Zeile, die mit / anfängt, ist ein Befehl, ein Auftrag fürs Spiel:

      
/spawn redback 5 3

      
    
        
  1. Cut the line into words at the spaces: spawn, redback, 5, 3.
    2. 
        
  2. Die Zeile an den Leerzeichen in Wörter schneiden: spawn, redback, 5, 3.
    3. 
        
  3. The first word picks the command. Each command knows what it wants next: "an enemy, then maybe a level, then maybe a count".
    4. 
        
  4. Das erste Wort wählt den Befehl. Jeder Befehl weiß, was er als Nächstes will: "einen Gegner, dann vielleicht ein Level, dann vielleicht eine Anzahl".
    5. 
        
  5. Read each word as what it should be: redback must be one of the game's enemies, 5 a whole number from 1 to 99.
    6. 
        
  6. Jedes Wort als das lesen, was es sein soll: redback muss einer der Gegner des Spiels sein, 5 eine ganze Zahl von 1 bis 99.
    7. 
        
  7. Run it: three level-5 Redbacks appear. Or, if a word doesn't fit, say what's wrong instead of crashing.
    8. 
        
  8. Ausführen: Drei Rotrücken mit Level 5 erscheinen. Oder, wenn ein Wort nicht passt, sagen, was falsch ist, statt abzustürzen.
    9. 
      

    

    

      
A command is just an object

      
Ein Befehl ist nur ein Objekt

      
dev({
  name: 'spawn',
  help: 'put enemies in this cube',
  args: [{ name: 'enemy', type: 'enemy' },
         { name: 'level', type: 'int', optional: true },
         { name: 'count', type: 'int', optional: true }],
  run({ enemy, level, count }) { ... },
