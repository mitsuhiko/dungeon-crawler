Two computers, one adventure

Zwei Computer, ein Abenteuer

Press O in the game and you can play together with up to three friends, each on your own computer.

Drück im Spiel O, und du kannst mit bis zu drei Freunden zusammen spielen, jeder an seinem eigenen Computer.

Here is the surprise: there is no "big game in the middle". Each computer runs the whole game, its own copy. They keep each other up to date by sending little messages over the network.

Jetzt kommt die Überraschung: Es gibt kein "großes Spiel in der Mitte". Jeder Computer lässt das ganze Spiel laufen, seine eigene Kopie. Sie halten sich gegenseitig auf dem Laufenden, indem sie sich kleine Nachrichten über das Netzwerk schicken.

Like two friends building the same Lego castle in two houses, on the phone: "I just put a red brick on the tower." The other one puts a red brick on their tower too.

Wie zwei Freunde, die in zwei Häusern dieselbe Lego-Burg bauen und dabei telefonieren: "Ich hab gerade einen roten Stein auf den Turm gesetzt." Der andere setzt auch einen roten Stein auf seinen Turm.

The hard part is not sending messages. It is that messages take time, and that the copies must never start telling different stories. This room is about how the game handles both.

Das Schwierige ist nicht, Nachrichten zu schicken. Es ist, dass Nachrichten Zeit brauchen, und dass die Kopien nie anfangen dürfen, verschiedene Geschichten zu erzählen. In diesem Raum geht es darum, wie das Spiel mit beidem umgeht.

One of you is the host: it is the host's world you play in. The others are guests. Everyone gets a number: the host is 0, the guests 1, 2 and 3, in the order they came. The number gives you your colour: blue, green, orange or violet.

Einer von euch ist der Gastgeber (Host): Ihr spielt in seiner Welt. Die anderen sind Gäste. Jeder bekommt eine Nummer: Der Gastgeber ist 0, die Gäste 1, 2 und 3, in der Reihenfolge, in der sie kamen. Die Nummer gibt dir deine Farbe: Blau, Grün, Orange oder Violett.

Finding each other: the room code

Sich finden: der Raumcode

Every computer on the internet has an address, but at home it hides behind your router, like a flat behind a front door with many bells. Two computers can't simply find each other.

Jeder Computer im Internet hat eine Adresse, aber zu Hause versteckt er sich hinter dem Router, wie eine Wohnung hinter einer Haustür mit vielen Klingeln. Zwei Computer können sich nicht einfach so finden.

So they ask a matchmaker first, a server on the internet (the game uses one called PeerJS). The host tells it: "I am room ABCD". The guest asks: "Where is room ABCD?" The matchmaker introduces them.

Darum fragen sie zuerst einen Vermittler, einen Server im Internet (das Spiel benutzt einen namens PeerJS). Der Gastgeber sagt ihm: "Ich bin Raum ABCD." Der Gast fragt: "Wo ist Raum ABCD?" Der Vermittler stellt sie einander vor.

NAT and PeerJS The router's trick is called NAT: all computers in your home share one internet address, and the router remembers which answer belongs to which flat. A letter from outside that nobody asked for gets thrown away. PeerJS is a small library the game loads, and its makers also run the free matchmaker. It uses WebRTC, built into every browser: each computer asks a helper server "what is my address outside?", and then both knock on each other's door at the same time. Now each router thinks the other's letters are answers and lets them in. If a router is too strict for that, the letters go through a relay server instead: a bit slower, but still encrypted.
NAT und PeerJS Der Trick des Routers heißt NAT: Alle Computer bei dir zu Hause teilen sich eine Adresse im Internet, und der Router merkt sich, welche Antwort zu welcher Wohnung gehört. Ein Brief von draußen, nach dem niemand gefragt hat, wird weggeworfen. PeerJS ist eine kleine Bibliothek, die das Spiel lädt, und ihre Macher betreiben auch den kostenlosen Vermittler. Sie benutzt WebRTC, das in jedem Browser steckt: Jeder Computer fragt einen Hilfsserver "Welche Adresse habe ich draußen?", und dann klopfen beide gleichzeitig an die Tür des anderen. Jetzt hält jeder Router die Briefe des anderen für Antworten und lässt sie herein. Ist ein Router dafür zu streng, gehen die Briefe stattdessen über einen Umleitungsserver: etwas langsamer, aber immer noch verschlüsselt.

From then on each guest talks directly to the host (peer to peer), not through the matchmaker. That's faster, and nobody in the middle reads along: the line is encrypted.

Ab dann redet jeder Gast direkt mit dem Gastgeber (Peer-to-Peer), nicht über den Vermittler. Das ist schneller, und niemand in der Mitte liest mit: Die Leitung ist verschlüsselt.

The guests don't call each other: the host passes on what they say, like a switchboard. So only the host has to be easy to reach.

Die Gäste rufen sich nicht gegenseitig an: Der Gastgeber gibt weiter, was sie sagen, wie eine Telefonzentrale. So muss nur der Gastgeber gut erreichbar sein.

The code has only letters, and never I or O: read out loud on the phone, an I looks like a 1 and an O like a 0.

Der Code hat nur Buchstaben, und nie I oder O: Am Telefon vorgelesen sieht ein I aus wie eine 1 und ein O wie eine 0.

How a code is made Wie ein Code entsteht

The real code: a room code

Der echte Code: ein Raumcode


    

      
roomCode picks 4 letters at random from CODE_LETTERS. That makes about 330,000 different codes: plenty, since a room only lives while you play.

      
roomCode wählt 4 zufällige Buchstaben aus CODE_LETTERS. Das gibt ungefähr 330.000 verschiedene Codes: genug, denn ein Raum lebt nur, solange ihr spielt.

      
peerId is the name the host gives the matchmaker. Everyone in the world shares the matchmaker, so the game puts its own name in front: cube-crawler-ABCD.

      
peerId ist der Name, unter dem sich der Gastgeber beim Vermittler meldet. Den Vermittler teilen sich alle auf der Welt, darum setzt das Spiel seinen eigenen Namen davor: cube-crawler-ABCD.

      
If the code is taken already, the game simply tries another one.

      
Ist der Code schon vergeben, probiert das Spiel einfach einen anderen.

    

  






  
Don't send the world, send the seed

  
Schick nicht die Welt, schick den Seed

  

    

      
A whole world is thousands of cubes with millions of triangles. Sending that would take ages.

      
Eine ganze Welt sind Tausende Würfel mit Millionen Dreiecken. Das zu schicken würde ewig dauern.

      
But you already know the trick: the same seed always builds the same world. So the host sends one number, and the guest's computer builds the very same world by itself, cube by cube, hill by hill.

      
Aber du kennst den Trick schon: Derselbe Seed baut immer dieselbe Welt. Also schickt der Gastgeber eine einzige Zahl, und der Computer des Gastes baut ganz von selbst genau dieselbe Welt, Würfel für Würfel, Hügel für Hügel.

What the seed can't know is what you changed: the monsters already beaten, the gates and chests opened, the cubes found, the loot lying around, the quests. That's the notebook from the memory room, and the host sends that along too.

      
Was der Seed nicht wissen kann, ist, was ihr verändert habt: die schon besiegten Monster, die geöffneten Tore und Truhen, die gefundenen Würfel, die herumliegende Beute, die Aufträge. Das ist das Notizbuch aus dem Gedächtnis-Raum, und das schickt der Gastgeber mit.

      
Your own character comes with you: your level, your bag, your sword. Only the world is the host's.

      
Deine eigene Figur nimmst du mit: dein Level, deine Tasche, dein Schwert. Nur die Welt gehört dem Gastgeber.

capturePose reads how all 14 bones of your hero are turned right now. Each turn is 4 numbers (a quaternion), so 56 numbers. The other game puts its copy of your hero in exactly that pose: walking, swinging, falling over, everything.

Who is the boss of a monster?

  
Wer bestimmt über ein Monster?

  

    

      
If two computers moved the same spider, each would throw its own dice ("turn left or right?") and soon there would be two spiders, in two different places. Two stories.

      
Würden zwei Computer dieselbe Spinne bewegen, würfelte jeder selbst ("links oder rechts abbiegen?"), und bald gäbe es zwei Spinnen an zwei verschiedenen Orten. Zwei Geschichten.

      
So every monster has one boss: of the players in its cube, the one with the lowest number. That's the host whenever the host is there. The boss's game decides where the monsters go and whom they bite. The others' games only show them, as the boss tells them.

      
Darum hat jedes Monster einen Chef: von den Spielern in seinem Würfel den mit der kleinsten Nummer. Das ist der Gastgeber, sobald er da ist. Das Spiel des Chefs entscheidet, wohin die Monster gehen und wen sie beißen. Die Spiele der anderen zeigen sie nur, so wie der Chef es ihnen sagt.

      
Monsters go after whoever is nearest, and switch only when another one is clearly nearer. Whoever hits a monster becomes its target.

      
Monster gehen auf den los, der am nächsten ist, und wechseln erst, wenn ein anderer deutlich näher ist. Wer ein Monster trifft, wird sein Ziel.

      
A kill gives everyone there the experience. The loot is shared: one sword on the floor, for whoever gets there first.

      
Ein besiegtes Monster gibt allen, die dabei sind, die Erfahrung. Die Beute wird geteilt: ein Schwert auf dem Boden, für den, der zuerst da ist.

Try it: messages take time

  
Probier es: Nachrichten brauchen Zeit

  

    

      
A message needs a few hundredths of a second to arrive, and never exactly the same. That's called lag.

      
Eine Nachricht braucht ein paar Hundertstelsekunden, bis sie ankommt, und nie genau gleich lang. Das nennt man Lag.

      
If Ben's game put Anna wherever the newest message says, she would hop 20 times a second, and stand still when a message is late.

      
Würde Bens Spiel Anna immer dahin setzen, wo die neueste Nachricht sagt, würde sie 20-mal pro Sekunde hüpfen und stehen bleiben, wenn eine Nachricht zu spät kommt.

      
So the game shows her a little in the past, 110 ms ago. By then it has the messages from just before and just after that moment, and blends between them, like the smoothing in the heartbeat room.

      
Darum zeigt das Spiel sie ein bisschen in der Vergangenheit, vor 110 ms. Bis dahin hat es die Nachrichten von kurz davor und kurz danach und mischt zwischen ihnen, wie beim Glätten im Herzschlag-Raum.

      
Make the messages slow and wobbly. When does blue start to stumble too?

      
Mach die Nachrichten langsam und wackelig. Wann fängt auch Blau an zu stolpern?

      Smoothing, in The Heartbeat
      Glätten, im Herzschlag
    

    

  






  
The real code: a little in the past

  
Der echte Code: ein bisschen in der Vergangenheit

  

    

    

      
Every message carries the time on the sender's clock (ts). But the two computers' clocks don't agree!

      
Jede Nachricht trägt die Uhrzeit von der Uhr des Absenders (ts). Aber die Uhren der beiden Computer stimmen nicht überein!

      
The trick: offset is the smallest "arrival time minus sent time" seen recently. It's the clocks' difference plus the fastest trip. With it, at works out what the sender's clock said DELAY ago.

      
Der Trick: offset ist das kleinste "Ankunftszeit minus Sendezeit", das zuletzt vorkam. Das ist der Unterschied der Uhren plus die schnellste Reise. Damit rechnet at aus, was die Uhr des Absenders vor DELAY gezeigt hat.

      
Then it finds the two messages around that moment and says how far between them it is: k from 0 to 1. The painter blends position and bones by k.

      
Dann sucht es die beiden Nachrichten um diesen Moment und sagt, wie weit dazwischen er liegt: k von 0 bis 1. Der Maler mischt Position und Knochen mit k.

    

  






  
Not waiting for the answer

  
Nicht auf die Antwort warten

  

    

      
When you hit a monster another game is the boss of, that game decides. But waiting for its answer would feel like hitting through jelly: swing, wait, then the spark.

      
Wenn du ein Monster triffst, dessen Chef ein anderes Spiel ist, entscheidet dieses Spiel. Aber auf seine Antwort zu warten würde sich anfühlen wie durch Wackelpudding schlagen: zuschlagen, warten, dann der Funke.

      
So your game guesses: it shows the hit at once, with its own result. For 1500 ms its own guess counts more than older news from the boss, which hasn't heard of the hit yet. After that, the boss's word counts again.

      
Darum rät dein Spiel: Es zeigt den Treffer sofort, mit seinem eigenen Ergebnis. 1500 ms lang zählt seine eigene Vermutung mehr als ältere Nachrichten vom Chef, der von dem Treffer noch nichts weiß. Danach zählt wieder das Wort des Chefs.

    

    

      
Your own hero isn't guessed at all: each computer moves its own player itself, so running and jumping never lag.

      
Deinen eigenen Helden muss das Spiel gar nicht raten: Jeder Computer bewegt seinen eigenen Spieler selbst, darum ruckeln Laufen und Springen nie.

      
Big online games do the same, just more of it. It's always a trade: what may each computer decide alone, so it feels quick, and what must one boss decide, so the story stays one?

      
Große Online-Spiele machen dasselbe, nur mehr davon. Es ist immer ein Abwägen: Was darf jeder Computer allein entscheiden, damit es sich schnell anfühlt, und was muss ein Chef entscheiden, damit die Geschichte eine bleibt?

    

  






  
One sword, first come

  
Ein Schwert: Wer zuerst kommt

  

    

      
The loot is shared: if it's on the floor for you, it's on the floor for everyone, and once someone picks it up, it's gone for all. So one computer must decide who got it: the host.

      
Die Beute wird geteilt: Liegt sie für dich auf dem Boden, liegt sie für alle da, und hebt sie jemand auf, ist sie für alle weg. Also muss ein Computer entscheiden, wer sie bekommen hat: der Gastgeber.

      
But again, waiting is no fun. Here a trick from the Magic Numbers room helps: loot comes from a seed. The same monster always drops the same sword. So whoever struck the last blow doesn't wait: their game rolls the drop and shows it at once, and tells the host (drop).

      
Aber auch hier macht Warten keinen Spaß. Da hilft ein Trick aus dem Zauberzahlen-Raum: Beute kommt aus einem Seed. Dasselbe Monster lässt immer dasselbe Schwert fallen. Darum wartet der, der zuletzt zugeschlagen hat, nicht: Sein Spiel würfelt die Beute aus, zeigt sie sofort und sagt es dem Gastgeber (drop).

      
The host keeps the first drop of each monster and tells everyone (loot). If two guessed at once, the second one's drop is swapped for the first one's.

      
Der Gastgeber behält den ersten Drop jedes Monsters und sagt es allen (loot). Haben zwei gleichzeitig geraten, wird der Drop des zweiten gegen den des ersten getauscht.

Exploring apart

  
Getrennt erkunden

  

    

      
You don't have to stay together. The coloured arrows on the map are your friends, each in their own colour, pointing where they look.

      
Ihr müsst nicht zusammenbleiben. Die bunten Pfeile auf der Karte sind deine Freunde, jeder in seiner Farbe, und sie zeigen, wohin sie schauen.

      
Alone in a cube, your own game is the boss of its monsters. When someone with a lower number walks in, the monsters change hands: your game sends them over exactly as they are (where they stand, how hurt they are, whether they're fighting) and theirs takes them over. When the boss leaves, the next lowest number there takes them back.

      
Allein in einem Würfel ist dein eigenes Spiel der Chef seiner Monster. Kommt jemand mit einer kleineren Nummer herein, wechseln die Monster den Besitzer: Dein Spiel schickt sie genau so, wie sie sind (wo sie stehen, wie verletzt sie sind, ob sie kämpfen), und seins übernimmt sie. Geht der Chef, übernimmt die nächstkleinere Nummer im Würfel sie wieder.

Help me up!

  
Hilf mir hoch!

  

    

      
Alone, a fatal blow means "You died": back to the entrance, or to the main menu. Together, you stay lying where you fell. The monsters leave you be.

      
Allein heißt ein tödlicher Treffer "Du bist gestorben": zurück zum Eingang oder ins Hauptmenü. Zusammen bleibst du liegen, wo du hingefallen bist. Die Monster lassen dich in Ruhe.

      
A friend stands next to you for 2 seconds, and you get up again. Nobody comes? After 30 seconds you died, just like alone.

      
Ein Freund stellt sich 2 Sekunden neben dich, und du stehst wieder auf. Kommt keiner? Nach 30 Sekunden bist du gestorben, genau wie allein.

    

    

      
Who decides that you're helped up? You: your game knows where your friends are (from their me messages) and counts. It tells them how far along it is, so their screens can say "Helping Ben up 60%".

      
Wer entscheidet, dass dir aufgeholfen wird? Du: Dein Spiel weiß aus den me-Nachrichten, wo deine Freunde sind, und zählt mit. Es sagt ihnen, wie weit es ist, damit auf ihren Bildschirmen "Ben aufhelfen: 60 %" stehen kann.

      
Going down and getting up also go to the friends as news, so their chat boxes say "Ben is down" even when they're far away.

      
Hinfallen und Aufstehen gehen auch als news an die Freunde, damit ihre Chat-Boxen "Ben liegt am Boden" sagen, auch wenn sie weit weg sind.

    

  






  
When the line breaks

  
Wenn die Leitung reißt

  

    

      
Networks break: the WiFi drops, someone closes the laptop. A computer that's gone can't say "I'm gone"!

      
Netzwerke gehen kaputt: Das WLAN fällt aus, jemand klappt den Laptop zu. Ein Computer, der weg ist, kann nicht sagen "Ich bin weg"!

      
So the host and each guest send each other a tiny ping every 1000 ms, even when nothing happens: "still here". No word at all for 12000 ms means: gone.

      
Darum schicken sich der Gastgeber und jeder Gast jede 1000 ms ein winziges ping, auch wenn nichts passiert: "bin noch da". 12000 ms lang gar kein Wort heißt: weg.

    

    

      
The guest then knocks again, a few times. Each page has its own secret player name (pid), so the host knows: "that's Ben again", and lets him back into the same world, where he was, with his old number.

      
Dann klopft der Gast noch ein paarmal an. Jede Seite hat ihren eigenen geheimen Spielernamen (pid), darum weiß der Gastgeber: "Das ist wieder Ben", und lässt ihn zurück in dieselbe Welt, wo er war, mit seiner alten Nummer.

      
A friend who said bye on purpose doesn't knock again.

      
Ein Freund, der absichtlich bye gesagt hat, klopft nicht wieder an.
