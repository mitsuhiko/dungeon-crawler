The Word Book

Das Wörterbuch

Every dotted word in the guide is explained here, in alphabetical order. The links take you to the room where it matters most.

Jedes gepunktete Wort im Rundgang wird hier erklärt. Die Links bringen dich in den Raum, in dem es am wichtigsten ist.

affix
Affix
A magic bonus on a sword, like "+5 damage" or "heals you on every hit". Prefixes go before the name, suffixes after it. Treasure & Weapons
Ein magischer Bonus auf einem Schwert, wie "+5 Schaden" oder "heilt dich bei jedem Treffer". Präfixe stehen vor dem Namen, Suffixe dahinter. Schätze & Waffen
AI model
KI-Modell
A program that was not written rule by rule, but learned from a huge pile of examples, like many hours of people talking. It is a giant list of numbers: what it learned. Not the same as a 3D model. Sounds, Music & Voices
Ein Programm, das nicht Regel für Regel geschrieben wurde, sondern aus einem riesigen Haufen Beispiele gelernt hat, zum Beispiel aus vielen Stunden sprechender Menschen. Es ist eine riesige Liste aus Zahlen: das, was es gelernt hat. Nicht dasselbe wie ein 3D-Modell. Geräusche, Musik & Stimmen
algorithm
Algorithmus
A step-by-step recipe for solving a problem, exact enough for a computer to follow. Finding a path is an algorithm, so is shuffling a deck of cards. Finding the Way
Ein Schritt-für-Schritt-Rezept, um ein Problem zu lösen, genau genug, dass ein Computer es befolgen kann. Einen Weg finden ist ein Algorithmus, Karten mischen auch. Den Weg finden
archetype
Archetyp
The big shape of a cube: plain, chasm, spire, sinkhole, archipelago, mesa or crater. Building the World
Die große Form eines Würfels: plain, chasm, spire, sinkhole, archipelago, mesa oder crater. Die Welt erschaffen
A* (A star)
A* (A-Stern)
A path-finding algorithm that always continues from the spot with the smallest "steps so far + guess of steps left". It finds the shortest path, and usually looks at far fewer squares than a flood. Finding the Way
Ein Wegfinde-Algorithmus, der immer beim Feld mit der kleinsten Summe aus "Schritte bisher + geschätzte Schritte bis zum Ziel" weitermacht. Er findet den kürzesten Weg und schaut meistens viel weniger Felder an als eine Flut. Den Weg finden
backtracking
Backtracking
Solving a puzzle by trying a step, and if it leads to a dead end, going back and trying a different step. Like solving a maze with a pencil. Building the World
Ein Puzzle lösen, indem man einen Schritt probiert und, wenn er in eine Sackgasse führt, zurückgeht und einen anderen probiert. Wie ein Labyrinth mit dem Bleistift lösen. Die Welt erschaffen
bake
backen
Working something out once, ahead of time, and keeping the result, so it doesn't have to be worked out again every frame. The game bakes the light and shadows of the lamps that stay when you come into a cube. Light and Shadow
Etwas einmal im Voraus ausrechnen und das Ergebnis aufheben, damit es nicht in jedem Bild neu ausgerechnet werden muss. Das Spiel backt das Licht und die Schatten der Lampen, die bleiben, wenn du in einen Würfel kommst. Licht und Schatten
BFS (breadth-first search)
Breitensuche (BFS)
Finding the way by spreading out like water: first everything 1 step away, then 2 steps, then 3. The first time you reach the goal, you have the shortest way. Finding the Way
Den Weg finden, indem man sich wie Wasser ausbreitet: zuerst alles 1 Schritt entfernt, dann 2, dann 3. Wenn du das Ziel zum ersten Mal erreichst, hast du den kürzesten Weg. Den Weg finden
cell
Zelle
One square of the floor grid. Every cube is 16 by 16 cells, and a cell is 1 unit wide. Welcome to Town
Ein Feld des Bodengitters. Jeder Würfel hat 16 mal 16 Zellen, und eine Zelle ist 1 Einheit breit. Willkommen in der Stadt
clip (animation)
Clip (Animation)
One animation of a model, like walking or jumping: a list of poses for its bones, 30 per second. Coming Alive
Eine Animation eines Modells, wie Gehen oder Springen: eine Liste von Posen für seine Knochen, 30 pro Sekunde. Lebendig werden
comment
Kommentar
A note in the code for people, after //. The computer skips it. Every file of the game starts with one that says what the file is for. Reading Code
Eine Notiz im Code für Menschen, nach //. Der Computer überspringt sie. Jede Datei des Spiels fängt mit einer an, die sagt, wofür die Datei da ist. Code lesen
depth
Tiefe
How far down a floor of the world is: 0 is the surface with the town, 20 is the core at the bottom. Each depth has its own look, monsters and song. Welcome to Town
Wie weit unten ein Stockwerk der Welt liegt: 0 ist die Oberfläche mit der Stadt, 20 ist der Kern ganz unten. Jede Tiefe hat ihr eigenes Aussehen, eigene Monster und ein eigenes Lied. Willkommen in der Stadt
dt (delta time)
dt (Delta-Zeit)
The time that passed since the last frame, usually about 1/60 of a second. Moving by "speed × dt" makes the game run at the same speed on fast and slow computers. The Heartbeat
Die Zeit seit dem letzten Bild, meistens etwa 1/60 Sekunde. Wer sich um "Tempo × dt" bewegt, ist auf schnellen und langsamen Computern gleich schnell. Der Herzschlag
face
Seite (Face)
The wall between two neighbouring cubes. It is decided once, so the ground, rivers and portals line up on both sides. Building the World
Die Wand zwischen zwei benachbarten Würfeln. Sie wird einmal entschieden, darum passen Boden, Flüsse und Portale auf beiden Seiten zusammen. Die Welt erschaffen
frame
Frame (Bild)
One picture of the game. The game draws about 60 frames every second, each a tiny bit different, like the pages of a flipbook. The Heartbeat
Ein Bild des Spiels. Das Spiel malt etwa 60 Bilder pro Sekunde, jedes ein winziges bisschen anders, wie die Seiten eines Daumenkinos. Der Herzschlag
function
Funktion
A little machine in the code with a name: you give it something, it gives something back. maxHealth(5) calls the machine maxHealth with 5. Reading Code
Eine kleine Maschine im Code mit einem Namen: Du gibst ihr etwas, sie gibt etwas zurück. maxHealth(5) ruft die Maschine maxHealth mit 5 auf. Code lesen
game loop
Spielschleife (Game Loop)
The code that runs again and again, every frame: listen to the player, update everything, draw the picture. The Heartbeat
Der Code, der immer wieder läuft, in jedem Bild: dem Spieler zuhören, alles aktualisieren, das Bild malen. Der Herzschlag
git
A tool that saves snapshots ("commits") of all the files of a project, with a message. You can always go back to an earlier snapshot, like a save point. Keeping It Working
Ein Werkzeug, das Schnappschüsse ("Commits") aller Dateien eines Projekts speichert, mit einer Nachricht. Du kannst immer zu einem früheren Schnappschuss zurück, wie zu einem Speicherpunkt. Damit alles läuft
graphics card (GPU)
Grafikkarte (GPU)
A chip in your computer made just for drawing: it fills in millions of triangles every second, and runs small programs (shaders) for every pixel. Drawing the World
Ein Chip in deinem Computer nur zum Malen: Er füllt Millionen Dreiecke pro Sekunde und führt für jeden Pixel kleine Programme (Shader) aus. Die Welt malen
graph
Graph
A map of things and their connections: which floor cells you can step between, for example. Path-finding works on graphs. Finding the Way
Eine Karte von Dingen und ihren Verbindungen: zum Beispiel, zwischen welchen Bodenzellen man treten kann. Wegfinden funktioniert auf Graphen. Den Weg finden
hash
Hash
A formula that turns anything (like a cube's name) into a number that looks random. The same input always gives the same number, but a tiny change gives a totally different one. Magic Numbers
Eine Formel, die alles (zum Beispiel den Namen eines Würfels) in eine Zahl verwandelt, die zufällig aussieht. Gleiche Eingabe gibt immer dieselbe Zahl, aber eine winzige Änderung gibt eine völlig andere. Zauberzahlen
heap
Heap
A to-do list that always hands you the item with the smallest number first, quickly. A* uses one to pick the next square to look at. Finding the Way
Eine Aufgabenliste, die dir immer schnell das Ding mit der kleinsten Zahl zuerst gibt. A* benutzt einen, um das nächste Feld zum Anschauen zu wählen. Den Weg finden
host
Gastgeber (Host)
Playing together, the player whose world it is, number 0. The guests talk to each other through the host's computer, and in a cube with guests it decides what the monsters do. Playing Together
Beim Zusammenspielen der Spieler, dem die Welt gehört, Nummer 0. Die Gäste reden über den Computer des Gastgebers miteinander, und in einem Würfel mit Gästen entscheidet er, was die Monster tun. Zusammen spielen
instancing
Instancing
Drawing many copies of the same model (like a hundred rocks) in one go, each with its own place. Much faster than drawing them one by one. Drawing the World
Viele Kopien desselben Modells (zum Beispiel hundert Steine) auf einmal malen, jede an ihrem eigenen Platz. Viel schneller, als sie einzeln zu malen. Die Welt malen
interface
Schnittstelle
An agreement between two parts of a program about what one hands to the other. As long as the agreement holds, each part can change on the inside without the other noticing. How It Fits Together
Eine Abmachung zwischen zwei Teilen eines Programms darüber, was der eine dem anderen gibt. Solange die Abmachung gilt, kann sich jeder Teil innen ändern, ohne dass der andere es merkt. Wie alles zusammenpasst
JavaScript
The programming language that every web browser understands. The whole game is written in it. Welcome to Town
Die Programmiersprache, die jeder Webbrowser versteht. Das ganze Spiel ist darin geschrieben. Willkommen in der Stadt
juice
Juice
The extras that make actions feel good without changing the rules: sparks, sounds, a tiny freeze on a hit, the camera shaking. Swords & Fighting
Die Extras, durch die sich Aktionen gut anfühlen, ohne die Regeln zu ändern: Funken, Geräusche, ein winziges Einfrieren beim Treffer, eine wackelnde Kamera. Schwerter & Kämpfe
lag
Lag
The time a message needs to get from one computer to another, a few hundredths of a second, and never exactly the same. Games hide it by showing others a little in the past. Playing Together
Die Zeit, die eine Nachricht von einem Computer zum anderen braucht, ein paar Hundertstelsekunden und nie genau gleich lang. Spiele verstecken sie, indem sie andere ein bisschen in der Vergangenheit zeigen. Zusammen spielen
lightmap
Lichtkarte (Lightmap)
A picture glued over the ground and walls, with the light (and shadows) of the lamps worked out once for each of its pixels, the texels. Drawing then just reads it. Light and Shadow
Ein Bild, das über den Boden und die Wände geklebt ist, mit dem Licht (und den Schatten) der Lampen, einmal für jedes seiner Pixel ausgerechnet, die Texel. Beim Malen wird es dann nur gelesen. Licht und Schatten
list (array)
Liste (Array)
Several values in a row, in square brackets: [1, 2, 3]. Counting starts at 0, so list[0] is the first one. Reading Code
Mehrere Werte hintereinander, in eckigen Klammern: [1, 2, 3]. Gezählt wird ab 0, also ist list[0] der erste. Code lesen
loop
Schleife
Code that runs again and again: for every monster in a list, or until a number is reached. Reading Code
Code, der immer wieder läuft: für jedes Monster in einer Liste, oder bis eine Zahl erreicht ist. Code lesen
message
Nachricht
A little letter one program sends another: an object turned into text, sent, and turned back into an object. Games playing together talk only with messages. Playing Together
Ein kleiner Brief, den ein Programm einem anderen schickt: ein Objekt, in Text verwandelt, verschickt und wieder in ein Objekt verwandelt. Spiele, die zusammen spielen, reden nur über Nachrichten. Zusammen spielen
model
Modell
A 3D object made of triangles, with colours, and often bones and animations. The hero, the monsters and the houses are models. Making Monsters
Ein 3D-Gegenstand aus Dreiecken, mit Farben und oft mit Knochen und Animationen. Der Held, die Monster und die Häuser sind Modelle. Monster bauen
NAT
NAT
Network address translation: the trick that lets all computers in a home share one internet address. The router remembers who asked for what, and throws away letters from outside that nobody asked for. That is why two computers need a matchmaker to find each other. Playing Together
Network Address Translation (Adressübersetzung): der Trick, mit dem sich alle Computer in einem Zuhause eine Internetadresse teilen. Der Router merkt sich, wer was gefragt hat, und wirft Briefe von draußen weg, nach denen niemand gefragt hat. Darum brauchen zwei Computer einen Vermittler, um sich zu finden. Zusammen spielen
network
Netzwerk
Computers connected so they can send each other messages: your home WiFi, and the internet, which connects all the networks of the world. Playing Together
Computer, die so verbunden sind, dass sie sich Nachrichten schicken können: dein WLAN zu Hause und das Internet, das alle Netzwerke der Welt verbindet. Zusammen spielen
noise
Rauschen (Noise)
Random numbers that change smoothly from place to place. Perfect for hills and valleys. Adding a big wavy layer and smaller wiggly layers makes it look natural. Building the World
Zufallszahlen, die sich von Ort zu Ort sanft ändern. Perfekt für Hügel und Täler. Eine große wellige Schicht plus kleinere zappelige Schichten sieht natürlich aus. Die Welt erschaffen
object
Objekt
A value with named parts, in curly brackets: { hp: 32, damage: 15 }. You read a part with a dot: SPIDER.hp. Reading Code
Ein Wert mit benannten Teilen, in geschweiften Klammern: { hp: 32, damage: 15 }. Einen Teil liest du mit einem Punkt: SPIDER.hp. Code lesen
peer to peer
Peer-to-Peer
Two computers talking directly to each other, not through a server in the middle. A matchmaker only introduces them at the start. Playing Together
Zwei Computer, die direkt miteinander reden, nicht über einen Server in der Mitte. Ein Vermittler stellt sie nur am Anfang einander vor. Zusammen spielen
perspective
Perspektive
Making far things look smaller than near things, by dividing by the distance. That's what makes a flat picture look 3D. Drawing the World
Ferne Dinge kleiner aussehen lassen als nahe, indem man durch die Entfernung teilt. Dadurch sieht ein flaches Bild nach 3D aus. Die Welt malen
photon
Photon
A tiny bit of light. A lamp sends out countless of them; where they land, it is bright. Light and Shadow
Ein winziges Lichtteilchen. Eine Lampe schickt unzählige davon aus; wo sie landen, ist es hell. Licht und Schatten
procedural generation
Prozedurale Erzeugung
Letting the computer invent content (worlds, swords, names) by following rules and rolling dice, instead of drawing everything by hand. Building the World
Den Computer Inhalte (Welten, Schwerter, Namen) erfinden lassen, indem er Regeln befolgt und würfelt, statt alles von Hand zu zeichnen. Die Welt erschaffen
profile
Profil
The list of numbers that describes a kind of monster: its health, damage, speed, how far it sees, how long its attacks take. Monster Brains
Die Liste von Zahlen, die eine Monsterart beschreibt: Gesundheit, Schaden, Tempo, wie weit es sieht, wie lange seine Angriffe dauern. Monster-Gehirne
program
Programm
A list of instructions a computer follows, exactly and very fast. A game is a program that runs in a loop and draws pictures. Welcome to Town
Eine Liste von Anweisungen, die ein Computer befolgt, ganz genau und sehr schnell. Ein Spiel ist ein Programm, das in einer Schleife läuft und Bilder malt. Willkommen in der Stadt
ragdoll
Ragdoll
A floppy body moved by physics instead of an animation: dots at the joints, held together by sticks. Used when the hero gets knocked over. Run, Jump, Fall
Ein schlabberiger Körper, der von Physik statt von einer Animation bewegt wird: Punkte an den Gelenken, von Stäben zusammengehalten. Kommt zum Einsatz, wenn der Held umgestoßen wird. Rennen, Springen, Fallen
recursion
Rekursion
When a function calls itself to solve a smaller part of the same problem. The route planner uses it to try one more step. Building the World
Wenn eine Funktion sich selbst aufruft, um einen kleineren Teil desselben Problems zu lösen. Der Routenplaner benutzt sie, um noch einen Schritt zu probieren. Die Welt erschaffen
reference
Referenz
A note that points to a thing instead of copying it. The quick bar holds references into your bag, so each potion exists only once. What the Game Remembers
Ein Zettel, der auf ein Ding zeigt, statt es zu kopieren. Die Schnellleiste hält Referenzen in deine Tasche, darum gibt es jeden Trank nur einmal. Was sich das Spiel merkt
SDF (signed distance field)
SDF (Distanzfeld)
Describing a shape with a formula that tells, for any point, how far it is from the surface (negative inside). Shapes made this way can melt together like clay. Making Monsters
Eine Form mit einer Formel beschreiben, die für jeden Punkt sagt, wie weit er von der Oberfläche weg ist (innen negativ). So gebaute Formen können wie Knete verschmelzen. Monster bauen
seed
Seed
The starting number for the computer's dice. The same seed always gives the same numbers, and so the same world. Magic Numbers
Die Startzahl für die Würfel des Computers. Derselbe Seed gibt immer dieselben Zahlen, und damit dieselbe Welt. Zauberzahlen
shader
Shader
A small program that runs on the graphics card, for every corner of every triangle or for every pixel. It decides colours, lights, fading and the cutaway. Drawing the World
Ein kleines Programm, das auf der Grafikkarte läuft, für jede Ecke jedes Dreiecks oder für jeden Pixel. Es entscheidet Farben, Licht, Überblendungen und den Ausschnitt. Die Welt malen
shadow map
Schattenkarte (Shadow Map)
A picture taken from a light's point of view that only keeps how far the light can see in each direction. A spot further away than that is in the shadow. Light and Shadow
Ein Bild aus Sicht eines Lichts, das sich nur merkt, wie weit das Licht in jede Richtung sehen kann. Ein Fleck, der weiter weg ist, liegt im Schatten. Licht und Schatten
solver
Löser
A program that solves a puzzle by trying every way, so it knows the fewest moves, and whether there is a way at all. The game checks every puzzle of a trial room with one before you get to see it. Building the World
Ein Programm, das ein Rätsel löst, indem es jeden Weg ausprobiert, und darum die wenigsten Züge kennt, und ob es überhaupt einen Weg gibt. Das Spiel prüft jedes Rätsel eines Prüfungsraums damit, bevor du es zu sehen bekommst. Die Welt erschaffen
state machine
Zustandsautomat
A brain that is always in exactly one state (like idle, chase or attack), with rules for when to switch to another one. Monster Brains
Ein Gehirn, das immer in genau einem Zustand ist (wie idle, chase oder attack), mit Regeln, wann es in einen anderen wechselt. Monster-Gehirne
telegraph
Ankündigung (Telegraph)
When a monster shows what it is about to do, like winding up before a bite, so you have a fair chance to dodge. Monster Brains
Wenn ein Monster zeigt, was es gleich tun wird, zum Beispiel vor einem Biss ausholt, damit du eine faire Chance zum Ausweichen hast. Monster-Gehirne
test
Test
A small program that checks that one part of the game still works the way it should. "npm test" runs all of them at once. Keeping It Working
Ein kleines Programm, das prüft, dass ein Teil des Spiels noch so funktioniert, wie es soll. "npm test" führt alle auf einmal aus. Damit alles läuft
three.js
A free JavaScript library that knows how to draw 3D with the graphics card. The game uses it for all the drawing. Drawing the World
Eine kostenlose JavaScript-Bibliothek, die mit der Grafikkarte 3D malen kann. Das Spiel benutzt sie für alles Malen. Die Welt malen
token
Token
One small piece an AI model reads or writes, one at a time. For text, a token is a word or a piece of a word. For the game's voices, a speech token is a number that stands for 80 milliseconds of sound. Sounds, Music & Voices
Ein kleines Stück, das ein KI-Modell liest oder schreibt, eins nach dem anderen. Bei Text ist ein Token ein Wort oder ein Stück davon. Bei den Stimmen des Spiels ist ein Sprach-Token eine Zahl, die für 80 Millisekunden Klang steht. Geräusche, Musik & Stimmen
variable
Variable
A name for a value, so the code can use the name. const makes one that never changes, let one that can. Reading Code
Ein Name für einen Wert, damit der Code den Namen benutzen kann. const macht einen, der sich nie ändert, let einen, der sich ändern kann. Code lesen
vector
Vektor
An arrow, written as numbers: how far to go along x, along z (and along y). A speed is a vector, and so is the way from you to a monster. Where Things Are
Ein Pfeil, als Zahlen geschrieben: wie weit entlang x, entlang z (und entlang y). Ein Tempo ist ein Vektor, und der Weg von dir zu einem Monster auch. Wo die Dinge sind
Verlet
A simple way to move things in physics: work out the speed from where a dot is now minus where it was a moment ago. It makes ragdolls easy and stable. Run, Jump, Fall
Eine einfache Art, Dinge mit Physik zu bewegen: Das Tempo ist, wo ein Punkt jetzt ist, minus wo er einen Moment vorher war. Damit werden Ragdolls einfach und stabil. Rennen, Springen, Fallen
WFC (wave function collapse)
WFC (Wave Function Collapse)
Filling a grid with puzzle pieces whose edges must match, always placing a piece where the fewest options are left. Building the World
Ein Gitter mit Puzzleteilen füllen, deren Kanten zusammenpassen müssen, und dabei immer dort ein Teil setzen, wo die wenigsten Möglichkeiten übrig sind. Die Welt erschaffen
weight
Gewicht
How likely a choice is, compared with the others. Like a bag with 40 white marbles and 8 blue ones. Magic Numbers
Wie wahrscheinlich eine Wahl im Vergleich zu den anderen ist. Wie ein Beutel mit 40 weißen und 8 blauen Murmeln. Zauberzahlen
web worker
Web Worker
A helper that runs code in the background, at the same time as the game, so the game doesn't freeze while it works. The world is invented in one. How It Fits Together
Ein Helfer, der Code im Hintergrund ausführt, gleichzeitig mit dem Spiel, damit das Spiel nicht einfriert, während er arbeitet. Die Welt wird in einem erfunden. Wie alles zusammenpasst
